# KPI's Segurança do Trabalho — Pessoas e Processos

Dashboard estático para a US Vale Verde, com duas visões integradas às planilhas públicas de KPIs do Google Sheets.

O navegador consulta diretamente as abas por Google Visualization Query (GViz). Para refletir alterações, basta editar as planilhas e recarregar o dashboard. Nenhuma cópia local dos dados é mantida.

## Regras de validade

- Licenças e condicionantes: a tabela mostra a validade e sinaliza revisão dentro dos 5 dias anteriores ao vencimento.
- Manutenção de trava-quedas: a tabela mostra a validade e sinaliza revisão dentro dos 45 dias anteriores ao vencimento.
- Extintores e ASOs: a validade muda para amarelo a partir de 30 dias restantes e para vermelho a partir de 15 dias restantes, incluindo vencimentos.
- Aderência de contratadas: o gráfico usa todos os meses disponíveis na base, incluindo agosto.
